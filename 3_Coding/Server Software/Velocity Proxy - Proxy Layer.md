**Velocity Proxy** - прокси-сервер для того, чтобы объединять подсервера с лобби и аренами.

Суть заключается в том, что через данный прокси игрок имеет только одну точку входа на игровой сервер с клиента, а не выбирает среди серверов нужный. Это жутко неудобно как для конечного игрока, так и есть большие риски потерять игрока, в случае если под упадёт и игрока просто выкинет с сервера. Шанс игрока в таком случае уйти с мини-игры будет очень высоким.

Прокси также позволяет выполнять роль балансировки нагрузки на лобби, на сами арены и так далее. По факту выполняет роль распределения нагрузки и детектирования проблемных серверов на уровне игры, а не условного Kubernetes.

## Самописные плагины

#### `arena-matchmaker` (Velocity)

**Задача:** распределение игроков по аренам + контроль за состояниями арен.
- Ведение “каталога арен”: какие Paper-сервера доступны, их режимы, лимиты, статус (healthy/degraded/full).
- Очереди (по режимам/приоритетам).
- Решение “куда посадить игрока”: выбрать арену, создать соединение и подключить к арене.
- Политика деградации на уровне сети: если все арены критичны/перегружены — направить в ожидание/лимбо, а не “ронять” UX.

**Почему на Velocity:** matchmaker - сетевой координатор. Ему удобнее быть рядом с точкой входа игроков.
